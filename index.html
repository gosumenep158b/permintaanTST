Dashboard Permintaan & Penjadwalan TST

Form Permintaan TST

Silakan lengkapi data di bawah untuk mengajukan permintaan TST.

Permintaan TST

Semua permintaan TST yang masuk dari siswa.

Antrian Permintaan TST

Permintaan yang menunggu dijadwalkan (sampai dengan 3 hari ke depan). Sheet "Penjadwalan TST" otomatis dibuat saat jadwal disimpan.

Jadwal TST

Daftar jadwal yang sudah ditentukan. Klik "Kirim WA" untuk menginformasikan ke siswa via WhatsApp.

Data Siswa

Data siswa diambil dari sheet "Siswa".

Pengaturan Admin

Username & password tersimpan di Script Properties. Default login: admin / admin123 - segera ganti password Anda.

Notifikasi Telegram

Setiap permintaan TST baru akan dikirim notifikasi ke Telegram admin. Buat bot di Telegram lewat @BotFather, lalu isi token bot dan chat ID di bawah.
